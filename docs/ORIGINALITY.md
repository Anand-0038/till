# Originality and attribution

Till is an original Professional Agents project developed for the Agents for Humans Hackathon
in this checkout. The checkout contained an initial prototype before this review pass; the
current implementation, tests, UI, diagrams, and documentation include iterative work by the
project's agents. Standard development tools and AI coding assistants were used during
implementation, consistent with the event rules.

The project includes the open-source Strands Agents SDK and the dependencies listed in
`requirements.txt`. Their licenses remain with their respective authors. The role skill files,
policy, close engine, UI, tests, and documentation in this repository are part of Till.

The seeded Tuesday register is synthetic. Till does not include real customer, payment, health,
or proprietary business data, and it does not connect to a real POS or move real money.
